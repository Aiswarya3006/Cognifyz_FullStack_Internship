# Cognifyz Technologies – Full Stack Development Internship

A collection of 8 Full Stack Development internship tasks completed as part of the Cognifyz Technologies Internship Program.

## About the Project

This repository contains beginner to expert-level projects demonstrating practical Full Stack Development concepts using HTML, CSS, JavaScript, Node.js, Express.js, REST APIs, authentication, middleware, background jobs and caching.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Node.js
- Express.js
- EJS
- REST APIs
- SQLite
- Git and GitHub

## Internship Tasks

### Level 1 – Beginner

**Task 1 – Basic Student Registration**
- HTML form structure
- Express server integration
- EJS server-side rendering
- Form submission

**Task 2 – Interactive Registration**
- Form validation
- In-memory data storage
- Registration confirmation
- Student records display

### Level 2 – Intermediate

**Task 3 – Responsive Web Design**
- Responsive layouts
- CSS Grid and Flexbox
- Navigation and course cards
- Mobile-friendly design

**Task 4 – Advanced Form Validation**
- Client-side and server-side validation
- Password strength indicator
- Dynamic DOM interaction
- Client-side navigation

### Level 3 – Advanced

**Task 5 – REST API CRUD Operations**
- Create, Read, Update and Delete
- Express REST API endpoints
- Front-end API interaction
- Fetch and display records

**Task 6 – Database and Authentication**
- SQLite database integration
- User authentication
- Password hashing
- Session management
- Role-based admin access

### Level 4 – Expert

**Task 7 – GitHub API and OAuth**
- GitHub public API integration
- Profile search
- Optional GitHub OAuth configuration
- API rate limiting
- Error handling

**Task 8 – Middleware and Background Jobs**
- Custom Express middleware
- Request logging and request IDs
- Scheduled background jobs
- Dashboard response caching
- Health check and error handling

## How to Run a Task

1. Clone the repository:

```bash
git clone https://github.com/Aiswarya3006/Cognifyz_FullStack_Internship.git
```

2. Open the required task folder.

3. Install dependencies:

```bash
npm install
```

4. Start the application:

```bash
npm start
```

5. Open the local URL specified in that task's README or server configuration.

## Important Notes

- Each task has its own README and package configuration.
- Task data stored in memory may reset when the server restarts.
- Task 7 supports GitHub OAuth when valid credentials are configured; otherwise, it runs in demo mode.
- Local databases, environment files and sensitive credentials are excluded from the repository.
